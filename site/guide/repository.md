# 저장소 구조

| 경로 | 내용 |
|---|---|
| `src/` | 관찰, World State, 판단, 계획, 실행을 맡는 Node.js·TypeScript 서버 |
| `ui/` | 대시보드, 모바일 포털, 설정, WebXR 페이지 |
| `apps/android/` | 네이티브 Android 앱과 Chrome TWA 브리지 |
| `twin/` | 집 배치와 3D 디지털 트윈 |
| `models/` | YOLO26 ONNX 모델 |
| `scripts/` · `tests/` | 영상 재생, 시연 준비, 서버·런타임 시험 |
| `deploy/` · `docs/` | 배포 설정, 구조 문서, 인터페이스 참조 |
